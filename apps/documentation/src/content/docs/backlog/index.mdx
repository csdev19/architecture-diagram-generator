# Backlog — What comes next

Planned work, proposals and improvements that are **not yet** implemented. Each
item carries enough context to be picked back up without re-researching. One
item = one row of the map (plus its own doc when it has substance).

**Status legend:** 🟡 In progress (paused) · 🟢 Ready to validate · 🔵 Proposed · ⚪ Idea

## How to use this section

- An item that starts being worked on moves to 🟡 and, when it has substance,
  gains its own doc in this folder (`backlog/<slug>.md`), linked from the
  **Detail** column.
- On completing an item: move the durable learning into the matching
  feature/architecture doc and remove it from the map (or mark it ✅ and
  archive it).
- Keep **Status** and **Effort** current — this map is the source of truth for
  "what's next".

### Template for an item with its own doc

```markdown

title: <Item title>

## Notes for picking it back up
<links, affected files, what was learned — enough to avoid re-researching>
```
