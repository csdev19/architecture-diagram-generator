🐛 **Fix** — The first full-stack run of this repository drew Cloudflare Workers twice: a tile in front of the app and a box around it, with the request routed through a hop it never makes. The repository prompts now say where something runs is the boundary, not a node. The pre-commit hook also no longer rejects a commit whose only formatted files are ones oxfmt ignores, such as `samples/*.json`.
