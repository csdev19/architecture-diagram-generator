✨ **Feature** — The Prompt tab now has two sources. **Project** hands a coding agent — Claude Code, Codex, Cursor — a prompt that reads a repository for its stack, not its logic, and returns the diagram JSON; a shape selector chooses between the runtime flow, the full stack with its tooling, and a layer-by-layer photograph, each explained in a line. The repository never leaves the machine: the agent reads it where it sits and only the JSON travels. **Image** is the sketch prompt as before.
