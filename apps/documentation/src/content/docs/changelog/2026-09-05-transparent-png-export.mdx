✨ **Feature** — File ▸ Export PNG 2× (transparent) rasterises the diagram with neither the paper nor the grid behind it, so it drops onto a slide or a document without carrying its own background. The ordinary export is unchanged, and the two carry different filenames so running both keeps both.
