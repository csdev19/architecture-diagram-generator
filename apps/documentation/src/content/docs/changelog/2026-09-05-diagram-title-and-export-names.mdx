✨ **Feature** — The diagram's title was only reachable by editing the JSON, so every export came out named after the seed example. It is now a field in the inspector, restricted to what a filename can hold, and every download — PNG, SVG and JSON — carries that title plus a local-time stamp. Exporting the same diagram twice keeps both files.
